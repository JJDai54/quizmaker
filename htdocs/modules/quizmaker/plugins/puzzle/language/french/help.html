puzzle : Jeux de mémoire et de logique avec des images

Description :

Ce plugin contient plusieurs jeux différents :
  • Puzzle : une image est découpé selon une grille pédéfinie, et l'utilisateur doit reconstituer l'image par du glisser déposer.
  • Taquine : une image esst découpée selon une grille prédéfinie dont il manque la case en bas à droite. le joueur doit reconstituer l'imagze par du glisser déposer uniquement sur les cases adjacentes à la case manquante.
  • Memory : une grille d'images est utilisée pour en construire une deuxième avec des doublons, des triplettes, .. Les image sont masquées au départ et le joueur doit trouver les cases ou se trouvent des images identiques. A chaque erreur les images sont de nouveau masquées.

    Objectif :

    Selon le jeu, reconstituer une image ou trouver des doublons ou des triplettes..

    Options :

    • points : Si (points == 0) alors c'est le nombre de points affectés aux bonnes et mauvaises réponses qui seront comptées. Si points > 0, c'est cette valeur qui sera utilisée pour le score.
      dans tous les cas il faut affecter un nombre de points aux bonnes réponses pour les identifier et calculer le bon score.
    • images (optionnelle): vous pouvez associer une image qui sera affichée selon le template qui sera sélectionné
    • hauteur de l'image : Défini la taille de l'image par la hauteur, attention aux images trop larges.
    • mélanger les propositions : la liste des caractère alphanumériques ou expression sera mélangée à chaque lancement du quiz..

    Propositions :

    Image :
    • Puzzle :   image a reconstitué par des Gliser/Déposer
    • Taquin : image a reconstitué par des déplacement su clicke souris contraint par la case manquante
    • Memory : Image constituée d'une grille d'images qui seront dupliquées dans la grille du joueur

    Proposition : texte affiché au dessus de la grille du joueur.

    Points :
    • Puzzle :   score obtenu en cas de succès
    • Taquin : score obtenu en cas de succès
    • Memory : nombre de points obtenu par images trouvée. Score = nombre d'images x points de la proposition.
