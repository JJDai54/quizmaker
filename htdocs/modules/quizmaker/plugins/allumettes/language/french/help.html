alumettes : Déplacer des allumettes et reconstituer la figure demandée.

Description :

Ce défi affiche une figure constituée de plusieurs allumettes que l'on peut déplacer ou faire tourner.

Objectif :

Déplacer ou faire tourner le nombre d'allumettes indiqué pour constituer une nouvelle figure.
Les allumettes se déplaces le long d'une grille qui permet un positioinnement précis et facilite e test de réussite.

Etape n° 2 : Définissez la position de départ proposée au joeur.
Pour cela ajouter autant d'allumettes que nécéssaire et positionner les sur la grille.

Ajouter une allumette mobile
 Ajoute une allumette rouge.
Ces allumettes pourront être déplacées ou tournées par le joueur
Ajouter une allumette fixe Ajoute une allumette noire.
Ces allumettes resteront fixes et ne pourront pas être déplacée par le joueur.
Mode suppression
 C'est un bouton à bascule qui permet de supprimer des allumettes qui auraient été ajoutée en trop.
Un petit bouton vert s'affiche pour chaque allumette, il suffit de cliquer dessus pour supprimer l'allumette.
Cliquez une deuxième fois sur ce bouton pour repasser en mode normal.
Redresser les allumettes Ce bouton aura pour effet de repositionner toutes les allumettes verticalement.
Gauche, Droite Haut Bas
 Ces boutons auront pour effet de déplacer l'ensemble des allumettes sur la grille du plateau de jeu.
Cele déplacera aussi les conbinaisons définies pour les solutions.



Etape n° 3 : Mémoriser la position de départ qui sera présentée au joueur , ligne "défi" :
Mémoriser
 Mémorise la position actuelle des allumettes
Restaurer
 Restaure la dernière position mémorisée. A utiliser notamment pour définir les solution possibles pour ne pas avoir à repositionner touets les allumetes, mais uniquement celles du défi.
Supprimer
 Supprime toutes les allumettes et mémorise le plateau vide.

Etape n° 4 : définissez les solutions possibles ligne 1 à 5 :
Il faut définir au moins une solution possible. Attention seule les solutions définies rapporteront des point au joueur en cas de succès. Il est donc important de bien vérifier que toutes les solutions possibles que le joueur pourraient constituée soit définies.
Pour féini une solution, commencer par restaurer la position de départ et mémorisez la dans une des solutions.
Déplacer ou ajouter les allumettes nécéssaires qui constitue une solution, puis mémorisez la solution.
Pour chaque solution les boutons "Mémoriser", "Restaurer", "Supprimer" permettent de gérer chacune d'elle.
"Cacher les allumettes fixes". Dans les solutions il n'est pas possible d'ajouter des allumettes fixes. Par contre il es possible de les masquer pour faciliter le positionnement. Dans tous les cas les allumetes fixes seront visibles par le joueur et ne pourront pas être déplacées.
N'oubliez pas de mémoriser chaque solution possible.

Etape n° 5 : Tester les solutions :
Restaurez la positioni de départ, le défi.
Déplacez les allumettes selon une des slotions possibles.
Cliquez sur le bouton ""Tester les solutions"
Si les allumettes sont correctement placée,s un message indiquant la solution correspondante sera affché, sinon le message "Aucune solution ne correspond" sera affiché.

Optionel :
Recaler les allumettes sur la grille : Cett option n'est à utilisée avec parcimonie, notamment dans le cas ou la taille des cellules de la grille aurait été modifiée.
Dans tous les cas si vous utilisez cette option, révéifiez la position de départ et toutes les solutions en cliqnant sur les bouton "Restaurer" correspondants, et rectifier la position des allumettes si besoin.
